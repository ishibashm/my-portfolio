お手数ですが、VSCodeの設定でデフォルトターミナルをWSLに変更していただけますでしょうか？

**手順:**

1. `Ctrl + Shift + P` (または `F1`) でコマンドパレットを開きます。
2. `Terminal: Select Default Profile` (または `ターミナル: デフォルトプロファイルの選択`) と入力し、選択します。
3. 表示されるリストから `WSL` (または `Ubuntu` などのディストリビューション名) を選択します。
4. 新しいターミナルを開く（既存のターミナルを閉じて `Ctrl + @` など）と、プロンプトがWSLのものに変わっているはずです。
